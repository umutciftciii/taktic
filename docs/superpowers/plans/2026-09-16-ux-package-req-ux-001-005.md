# REQ-UX-001–005 UX Package Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task (inline; the session owner asked for no subagents). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the five REQ-UX items (status-driven success screen, Istanbul date range, provider choice cards with draft hand-off, offer-experience fixes, landing copy) as one PR on top of `origin/main` @ `16b5c703`, with API + web + E2E proof and no business-rule changes.

**Architecture:** One additive Prisma column (`ServiceRequest.preferredDateEnd`), one additive customer endpoint (`GET /service-requests/my/:id`), additive projection fields (`viewedAt`, `preferredDateEnd`). Date-only logic lives in `@taktic/shared` for web/admin and in `apps/api/src/common/date-only.ts` for the API (the API cannot import the shared package). The showcase hand-off reuses `RequestDraft` (SHOWCASE_LEAD key) — no new storage, no PII in URLs.

**Tech Stack:** NestJS 11 + Prisma 6 (API, vitest+supertest), Next 15 app router (web), Playwright (Chromium + WebKit), pnpm/turbo.

## Global Constraints

- No new dependencies. No changes to compose/Dockerfile/env/scheduler/payments/Lemon/Resend/Cloudflare.
- No changes to offer state machine, credit/refund maths, provider review thresholds, or the vitrin lead rules (mandatory phone verification, urgencyBucket, SLA).
- `POST /service-requests` gets **no** `showcaseCardId`; `RequestDraftPayloadDto` gets **no** contact fields.
- All calendar maths on `YYYY-MM-DD` strings in `Europe/Istanbul`; never the server's UTC day.
- Exact copy: success `TALEP YAYINLANDI` / `Talebiniz yayınlandı`; guest `TALEP ALINDI` / `Talebiniz alındı` / `Talebiniz işleme alındı. Gelişmeleri hesabınızı etkinleştirdikten sonra takip edebilirsiniz.`; withdrawn `Bu teklif hizmet veren tarafından iptal edilmiştir.`; hand-off CTA `Seçili işletmeye devam et`; hand-off note `Seçili işletmeye talep göndermek için telefonunuzu doğrulamanız gerekir.`; landing `Talepleri gör`.
- Tests: run existing suites first; `pnpm typecheck && pnpm lint && pnpm test && pnpm build`; Chromium + WebKit E2E; migration dry-run only on an isolated throwaway DB.
- Worktree env: `DATABASE_URL='postgresql://taktic_user:taktic_password@localhost:5433/taktic?schema=public'` inline; `pnpm db:generate` after schema edits; run E2E with `pnpm e2e <filter>` (no `--`).
